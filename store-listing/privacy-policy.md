# Larik SQL Studio — Privacy Policy

Last updated: 11 November 2026

Larik SQL Studio ("Larik", "the app") is a desktop SQL studio for Windows. This policy describes
what the app does with information. It is written for the Microsoft Store edition of the app.

## Summary

- Larik does not collect telemetry, analytics or usage data.
- Larik has no user accounts and no sign-in.
- Larik connects only to the database servers you configure.
- Your workspaces, tabs and SQL are stored on your device.
- Passwords are stored in Windows Credential Manager, not in app files.

## What is stored on your device

Larik stores your workspaces, query tabs, SQL text, editor and UI preferences, and connection
profiles in the app's own local data folder. This data stays on your device. You can remove it by
deleting the app's data or uninstalling the app.

Connection profiles contain the details you enter (server, database, user name and similar
provider settings). Password fields declared by a database provider are not written to the
profile; they are kept in Windows Credential Manager and protected by Windows.

## Network connections

Larik opens a network connection only when you connect to a database. The destination is the server
you entered in the connection dialog. Larik does not send your queries, results, schema or usage
information anywhere else.

This edition does not check for updates over the network. Updates are delivered by the Microsoft
Store, and the Store client handles that traffic under Microsoft's own privacy terms.

If you use a database server hosted by someone else, that server's operator has its own policy.

## What Larik does not do

- No telemetry or analytics.
- No advertising and no ad identifiers.
- No crash reporting service.
- No selling or sharing of personal information.
- No access to files outside the app's data folder and the paths you choose for exports.

## Children

Larik is a developer tool and is not directed at children. It does not knowingly collect
information from anyone, including children.
